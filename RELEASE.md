# KI Varslinger 1.2.0

- Ny hovedbryter **Alle varsler** for oppsett med flere varselvalg: familie og alarm.
- Slår automatisk varsling for hele oppsettet av/på uten å endre enkeltvalgene.
- Hovedbryterens tilstand og de individuelle valgene lagres ved omstart.
- Ved oppgradering starter hovedbryteren på. Eksisterende enkeltvalg beholdes.
- Oppsett med én varselbryter får ingen ekstra bryter.
- Testknapper kan fortsatt brukes når hovedbryteren er av. Hovedbryteren for alarm stanser også automatiske kritiske alarmvarsler.

Oppdater gjennom HACS og start Home Assistant på nytt. Den nye bryteren opprettes automatisk på eksisterende familie- og alarmenheter; oppsettene trenger ikke legges til på nytt. Legg «Alle varsler» til på dashbordet fra integrasjonens enhet.
